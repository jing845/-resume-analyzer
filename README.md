# 简历诊断助手

个人 AI 应用项目。将岗位要求、简历证据、信息缺口和下一步建议放在一起，帮助求职者在真实事实范围内改善表达。

## 本次更新

- 默认展示明确标注的虚构样例，无需模型服务即可查看。
- 三类岗位对照同一份虚构简历，说明岗位需求如何影响判断。
- 实时结果按要求逐条展示依据，取消未经校准的总分及 HR 推荐语。
- 校验模型引文是否出现在原文；不符合时标记待核对。
- 逐段改写保留事实，检查新增数字和部分职责扩大表达；规则不能替代人工确认。
- 修复失败仍显示成功、未输入便改写、结果随操作消失等问题。
- DOC 识别后给出转换提示；DOCX 增加表格内容读取。
- 输入仅保留在当前 Streamlit 会话中，不主动写入简历数据库。

## 更新线上应用

将本目录里的 app.py、core.py、config.py、samples.json、requirements.txt 和 README.md 上传或替换到原 GitHub 仓库根目录。保留 Streamlit Settings → Secrets 内的 API_KEY，不要把真实密钥提交到 GitHub。

Secrets 的 API_KEY 名称与原版本一致。BASE_URL 和 MODEL 为可选配置，未设置时沿用原服务地址和模型。

更新 requirements.txt 会触发依赖重装，完成后检查 Streamlit 的运行日志和样例页面。若不希望自动更新线上，先在分支验证。

## 本地运行

安装 requirements.txt 中的依赖，配置环境变量 API_KEY，然后运行 streamlit run app.py。没有密钥也可以查看预置样例。
